#Atividade 2 - Projeto Sorteio (Cara ou Coroa)

#Instruções
2025.1 - PDM I – Atividade 2 - Projeto Sorteio (Cara ou Coroa) - Android NodeJS RN. 


Desenvolver uma aplicação com react-native para SO Android que simula um sorteio de cara e coroa. 
O usuário pode escolher a opção (de cara ou cora) através de Picker. 

O aplicativo deve conter os seguintes objetos: 

Image (com as imagens de cara ou coroa), 

Picker (Para selecionar a opção de [cara ou coroa]), 

e button para fazer o sorteio. 

O Aplicativo de deve contar a quantidade de vezes que foi solicitado o sorteio, apresentar as estatísticas de quantas vezes o usuário acertou e quantas a vezes a máquina (Aplicativo) saiu vencedora. 

Obs:- O código fonte dos arquivos deve estar separado.
