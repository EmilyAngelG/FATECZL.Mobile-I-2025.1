#Atividade: Criando um Cartão de Produto Reutilizável com React Native

Objetivo:
Você vai criar um pequeno aplicativo em React Native usando Expo CLI, com o objetivo
de praticar o uso de componentes reutilizáveis, também conhecidos como "fragmentos
visuais", que podem ser utilizados em várias partes da interface.

#Requisitos:
1. Crie um projeto com Expo CLI chamado ProdutosApp.
2. Crie um componente chamado ProductCard no diretório components/ que exiba:
o Imagem do produto
o Nome do produto
o Preço do produto
3. No App.js, crie uma lista com pelo menos 6 produtos (cada um com nome,
imagem e preço). Pode ser uma lista em JSON 
4. Use o componente ProductCard para exibir todos os produtos.
5. Estilize o cartão com bordas arredondadas, sombra e layout centralizado.
6. (Desafio extra) Adicione um botão "Comprar" que, ao ser clicado, exiba um
alerta com a mensagem: Produto [NOME] comprado! (Pode usar um modal)

Estrutura Esperada:
/ProdutosApp
/components
ProductCard.js
App.js
